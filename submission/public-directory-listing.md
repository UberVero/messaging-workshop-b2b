## Listing copy

**Short description**

Build a proof-backed B2B messaging source of truth.

**Long description**

Build the messaging foundation your whole company can reuse. The B2B Messaging Workshop guides you through company context, customer problems, competitive alternatives, personas, value, positioning, and proof—one focused question at a time. It keeps facts separate from hypotheses, preserves sourced customer language, lets you pause and resume, and pressure-tests the finished framework before producing a clean Product Marketing Source of Truth.

## Reviewer note

This is a skills-only plugin. It has no MCP server, external API, account creation, payment flow, or Eldur-hosted data collection. The workshop runs inside the OpenAI product. The optional Notion delivery step is used only when the user explicitly requests and confirms it.
